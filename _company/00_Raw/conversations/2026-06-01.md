# 🖼️ Visual Sequence Module (VSM) 시각 일관성 명세서

**목표:** 스크립트 변화에 따라 필요한 시각적 전환점(B-roll 삽입 지점)을 자동 매핑하며, Cortexa의 브랜드 아이덴티티(#2C3E50, #F1C40F)를 엄격히 적용하여 영상의 몰입도와 전문성을 극대화한다.

## 1. 브랜드 디자인 가이드라인 적용 규칙

모든 시각적 전환(Transition) 및 삽입(Insertion)은 다음 색상 팔레트와 타이포그래피 원칙을 따라야 한다.

*   **Primary Color (배경/텍스트):** `#2C3E50` (짙은 네이비/차콜 계열)
    *   사용 목적: 주요 정보, 배경, 전문적인 톤 설정.
*   **Accent Color (강조/액션):** `#F1C40F` (골드/밝은 오렌지 계열)
    *   사용 목적: 핵심 전환점 강조, CTA 시각화, 이탈률 모니터링 지표 표시.

## 2. VSM 입력 요구사항 (Input Requirements)

VSM은 스크립트 분석 결과에서 다음 데이터를 입력받아 시각적 요구사항을 도출해야 한다.

| 필드명 | 데이터 타입 | 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| `timestamp` | number (ms) | 영상 내 실제 시간 좌표 (전환이 발생할 정확한 지점). | 필수 |
| `visualCue` | string | 필요한 시각적 요소에 대한 **텍스트 설명**. (예: "데이터 흐름 애니메이션", "차트 전환 효과") | 핵심 |
| `durationMs` | number (ms) | 해당 시각적 큐가 화면에 유지되어야 하는 권장 시간. | 최적화 |
| `contextualFocus` | string | 해당 시퀀스가 전달하는 핵심 감정/정보 상태. (예: "복잡성 해소", "핵심 발견") | 디자인 매핑용 |

## 3. VSM 출력 요구사항 (Output Requirements)

VSM은 입력된 데이터를 기반으로 최종적으로 렌더링 엔진에 제공할 **시각적 마스터 지침(Visual Master Directive)**을 출력해야 한다.

**출력 형식:** JSON 객체 형태로, 각 시퀀스별로 다음과 같은 구조를 포함해야 한다.

```json
{
  "sequenceId": "S001", // 고유 식별자
  "timing": {
    "startMs": 125000, // 시작 시간 (Video Timestamp)
    "durationMs": 3000 // 유지 시간
  },
  "visualInstruction": {
    "type": "Transition", // 또는 "Insert_Broll", "Highlight", "DataVisualization" 등
    "style": "GradientFlow", // 적용할 스타일 (예: GradientFlow, SolidBlock)
    "colorScheme": {
      "primary": "#2C3E50",
      "accent": "#F1C40F"
    },
    "layoutConcept": "SplitScreen_FocusEscape", // 레이아웃 원칙 적용 (예: 화면을 50:50으로 분할)
    "focusState": "FocusAndEscape" // 이 시퀀스가 유도하는 심리적 상태 태그
  },
  "visualAssetReference": {
    "assetId": "BROLL_DATA_FLOW_01", // 사용될 비주얼 자산의 ID 참조
    "metadata": "고해상도 데이터 흐름 애니메이션 파일 경로 또는 라이브러리 참조"
  }
}
```

## 4. 디자인 실행 원칙 (Execution Principles)

1.  **색상 일관성:** 모든 시각적 요소는 `#2C3E50`을 주조색으로 사용하고, `#F1C40F`를 **극도의 강조점**으로만 사용하여 전문적인 느낌을 유지한다.
2.  **레이아웃 원칙:** `layoutConcept` 필드를 통해 영상의 흐름(Focus & Escape)에 따라 화면 분할, 오버레이, 중앙 집중 등의 레이아웃 전략이 자동 결정되어야 한다.
3.  **모듈화:** 모든 시각적 큐는 미리 정의된 마스터 템플릿 내에서 사용 가능한 자산(`visualAssetReference`)을 참조하도록 설계하여, 디자인의 재사용성을 확보한다.

## VSM 및 썸네일 자동화 ROI 및 가격 전략 재분석 보고서

요청하신 Visual Sequence Module(VSM)이 생성하는 시각적 자산과 기존 썸네일 자동화 전략 간의 ROI 분석 및 최적의 가격 책정 전략을 재분석했습니다. 이는 **'품질 기반 프리미엄 수익 모델'**로 전환하는 데 초점을 맞춥니다.

### 1. 현황 진단: 두 요소의 역할 분리 및 시너지 (ROI 분석)

| 요소 | 주요 기능 | 현재 ROI 기여도 (추정) | 전략적 포지셔닝 |
| :--- | :--- | :--- | :--- |
| **VSM (Visual Sequence Module)** | 영상 내 시각적 일관성 및 고품질 자산 생성 (시스템 기반) | 잠재력 높음 (미완성된 시스템의 가치) | **고가치 입력 자원 (Input Asset)** |
| **썸네일 자동화** | 콘텐츠 제작 속도 극대화 및 마케팅 효율 증대 (시간 절약) | 즉각적이고 명확함 (효율성 기반) | **운영 효율화 도구 (Operational Tool)** |

**ROI 재분석:**
기존의 썸네일 자동화는 주로 **'비용 절감(Cost Reduction)'**에 초점을 맞추어 제작 시간을 줄이는 데 기여했습니다. 반면, VSM은 콘텐츠 자체의 **'질적 가치(Quality Value)'**를 극대화합니다.

*   **기존 ROI:** 시간 비용 절감 $\rightarrow$ 생산성 향상
*   **재분석된 ROI (VSM 통합):** 시각적 일관성 확보 $\rightarrow$ 고객 이탈률 감소 및 체류시간 증가 $\rightarrow$ **평균 수익당 사용자(ARPU) 극대화**

**결론:** VSM은 단순한 자산 생성 도구가 아니라, 콘텐츠의 **'프리미엄 브랜드 경험(Premium Brand Experience)'**을 담보하는 핵심 요소입니다. 자동화는 이 프리미엄 자산을 시장에 빠르게 배포하기 위한 효율적인 마케팅 채널로 기능해야 합니다.

    *   **가격 전략:** 중간 가격 책정 (Value-Based). 월 $Y (시간 절약보다 '퀄리티 보장'에 대한 비용 지불 유도).

3.  **Tier 3: Pro/Accelerator Pack (최고가)**
    *   **내용:** Tier 2 기능 + 실시간 KPI 모니터링 연동, 맞춤형 시각 전략 컨설팅 제공.

    *   **목표:** 고가치 고객(High-LTV) 확보 및 시스템의 완전한 수익화 극대화.

1.  **Stage 1: Input Gateway (API Endpoint)**

    *   **입력 데이터:** `script_text`, `visual_guidelines` (디자인 가이드라인 포함).

2.  **Stage 2: VSM Core Execution (Backend Logic)**
    *   API Gateway에서 받은 데이터를 내부의 **Visual Sequence Module (VSM)** 로직으로 전달합니다.
    *   VSM은 입력된 스크립트와 디자인 가이드라인을 기반으로, 'Focus & Escape' 전략에 따라 시각적 전환점(Transition Points)과 B-roll 삽입 지점을 계산합니다.

3.  **Stage 3: Output Generation (Result Formatting)**
    *   VSM의 계산 결과를 **구조화된 JSON 형식**으로 출력합니다. 이 JSON은 후속 시스템이 즉시 사용할 수 있도록 명확해야 합니다.
    *   **출력 데이터 예시:**

성공한 영상들은 세 가지 핵심 심리학적/구조적 패턴을 활용하여 시청자의 이목을 즉각적으로 사로잡습니다.

### A. 인간 본성에 대한 깊은 통찰 (The Psychology Hook)
* **패턴:** 단순히 사실(Fact)을 나열하는 대신, 특정 트렌드가 발생하는 *인간의 심리*와 연결합니다. ('가성비' 대신 '납득감', 샤머니즘과 불안).
* **효과:** 시청자가 자신의 경험과 감정을 투영하게 만들어 콘텐츠에 대한 몰입도(Engagement)를 극대화하고, 댓글 참여율을 높입니다.

### B. 거시적 트렌드와 미시적 적용의 연결 (Macro to Micro Linkage)
* **패턴:** 거대한 사회/기술 트렌드(AI, MZ세대, 에너지)를 다루면서, 이를 일상생활이나 비즈니스(마케팅, 소비, 업무 효율)에 즉각적으로 적용할 수 있는 구체적인 해결책을 제시합니다.
* **효과:** 시청자가 "이 정보를 내 삶/비즈니스에 바로 써먹겠다"는 실용성을 느끼게 하여 시청 지속 시간(Watch Time)을 늘립니다.

### C. '불안'과 '기회'의 프레이밍 (Fear & Opportunity Framing)
* **패턴:** 현재의 변화를 단순한 흐름이 아닌, 놓치면 안 될 *위험(불안)* 또는 반드시 잡아야 할 *기회*로 포장합니다. (예: AI Agents 마스터 클래스, Agentic Business).
* **효과:** 시청자의 FOMO(Fear Of Missing Out) 심리를 자극하여 클릭을 유도하고, 채널의 권위와 전문성을 높입니다.

| 모듈 | 역할 | 입력 | 출력 | 핵심 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **Input Processor** | 스크립트/스크립트 변환을 분석하여 시각적 전환점(VSM)을 추출합니다. | 영상 스크립트 (Text) | VSM 매핑 데이터 (JSON) | 텍스트에서 시각적 요구사항 분리 |

#### 2. 상세 데이터 흐름 및 안정성 확보 방안

**단계 1: Input Processor (스크립트 → VSM 매핑)**
*   **입력:** 영상 스크립트 (`.md` 또는 `.txt`).
*   **처리 로직:** LLM/NLP 기반으로 스크립트를 분석하여 'Focus & Escape' 전략에 따른 시청 지속률 극대화 지점(예: 0~35초, 5분 지점)을 식별하고, 각 지점에 필요한 시각적 전환(B-roll 삽입)의 종류와 양을 정의합니다.
*   **안정성:** 스크립트 분석 결과가 디자인 가이드라인(#2C3E50, #F1C40F) 내에서 유효한지 검증하는 **Validation Layer**를 추가합니다. (VSM 요구사항과 텍스트 매핑의 일관성 검사)

**단계 2: VSM Engine (매핑 → 레이아웃 지침)**
*   **입력:** 단계 1에서 추출된 시각적 요구사항 및 마스터 템플릿 구조.
*   **처리 로직:** VSM 엔진은 추상적인 시각적 요구사항을 구체적인 디자인 파라미터(프레임 비율, 색상 적용 범위, 요소 배치 좌표)로 변환합니다. 이는 `developer.md`에서 설계한 **Visual Sequence Module의 핵심 로직**을 직접적으로 활용합니다.
*   **안정성:** 모든 출력은 마스터 템플릿의 경계 내에 있는지 확인하는 **Boundary Check**를 수행하여, 비현실적인 레이아웃 생성을 원천 차단합니다.

**단계 3: Asset Generator (지침 → 최종 자산)**
*   **입력:** 구체화된 디자인 파라미터 및 마스터 템플릿 구조.
*   **처리 로직:** 정의된 지침에 따라, AI 이미지 생성 API(또는 기존 에셋 라이브러리)를 호출하여 썸네일의 배경, 텍스트 오버레이, 브랜드 색상(#2C3E50, #F1C40F)를 정확히 적용합니다.
*   **안정성:** **End-to-End 테스트 루프**(`run_final_deployment_test.py` 기반)를 이 단계에 통합합니다. 생성된 파일의 해상도, 포맷, 색상 일관성을 자동 검증하고 실패 시 즉시 재실행(Self-Correction Loop)을 수행합니다.

#### 3. 기술 스택 제안 (Technology Stack Suggestion)
*   **Backend/Orchestration:** Python (FastAPI 또는 Scripting for rapid prototyping). VSM Engine 및 Input Processor 로직 구현에 적합.
*   **Core Logic:** Python 기반으로, 데이터 처리 및 파일 시스템 조작에 용이함.

### 1. 핵심 측정 지표 (KPIs) 정의

### 2. 비즈니스 로직 요구사항 (Business Logic Requirements)

대시보드는 단순히 데이터를 보여주는 것을 넘어, **행동 기반의 전략적 통찰**을 제공해야 합니다.

1.  **인과관계 명시 (Causality Linking):** 모든 이탈률 데이터는 VSM 적용 여부(Consistency Pack 구독 여부)와 직접적으로 연결되어야 합니다. "Focus 모듈 적용 후 AVD가 X% 증가했다"와 같이 인과관계를 명확히 제시해야 합니다.
2.  **이상 징후 경고 (Anomaly Alerting):** 실시간으로 설정된 기준치(예: 특정 구간 이탈률이 평소 대비 15% 이상 높을 경우)를 초과하면 즉시 알림을 발생시켜, 콘텐츠 제작자나 시스템 관리자가 개입할 수 있는 '실시간 액션 포인트'를 제공해야 합니다.
3.  **패키지 가치 검증 (Value Validation):** 각 Consistency Pack 구성 요소(예: Focus Pack vs. Escape Pack)가 사용자 이탈률 감소에 기여하는 정도를 정량적으로 분석하여, 향후 **업그레이드 또는 신규 패키지 가격 책정의 근거**로 활용합니다.
4.  **ROI 기반 권고 (ROI-Based Recommendation):** 대시보드는 단순히 과거 데이터를 보여주는 것을 넘어, "현재 이탈률을 개선하기 위해 [특정 모듈] 사용을 권장함"과 같이 **구체적인 행동 권고(Actionable Advice)**를 제시해야 합니다.
