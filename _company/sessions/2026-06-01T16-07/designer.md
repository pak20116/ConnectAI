<create_file path="sessions/2026-06-01T12-07/designer.md"># 🖼️ 최종 시각 일관성 검증 체크리스트 (Asset Pack 표준)

## 🎯 목표
자동화된 디자인 시스템(썸네일 포함)이 Cortexa의 브랜드 정체성을 **100% 일관되게** 반영하도록 보장한다. 모든 자산 팩 제작 전, 아래 항목을 통과해야만 승인된다.

## 🔑 섹션 1: 브랜드 아이덴티티 준수 (Brand Identity Adherence)
| No. | 검증 항목 | 기준 (Design Spec 기반) | 자동화 체크 방식 | 통과 여부 (Y/N) | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1.1 | **Primary Color** 사용 | 주조색 `#2C3E50` 및 보조색(#FFFFFF, #F4F4F9 등)만 사용되었는가? | Hex 코드 검증 (시스템이 지정된 팔레트 내에서만 색상을 선택했는지 확인) | | |
| 1.2 | **Accent Color** 사용 | 강조색(Accent Color)은 정의된 범위 내에서 정확히 사용되었는가? | Accent Color 값 비교 및 오버랩 검사 | | |
| 1.3 | **Typography Scale** 준수 | 지정된 타이포그래피 계층 구조(H1, H2, Body 등)와 크기 비율이 유지되었는가? | 폰트 사이즈 대비 비율 검증 (예: 제목/본문 비율 확인) | | |
| 1.4 | **Font Family** 적용 | 지정된 기본 서체(예: Inter, Montserrat 등) 및 보조 서체가 일관되게 사용되었는가? | 폰트 매칭 검사 | | |

## 📐 섹션 2: 구조 및 레이아웃 일관성 (Structure & Layout Consistency)
| No. | 검증 항목 | 기준 (Focus/Escape 원칙 기반) | 자동화 체크 방식 | 통과 여부 (Y/N) | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 2.1 | **Focal Point** 배치 | 핵심 메시지(Focus)가 시각적으로 가장 먼저 인지되도록 배치되었는가? | 시선 흐름 분석 (Eye-tracking simulation) | | |
| 2.2 | **Escape Element** 활용 | 대비 효과를 통해 시청자의 주의를 다음 단계(Escape)로 유도하는 요소가 포함되었는가? | 명암비 및 색상 대비 측정 | | |
| 2.3 | **Layout Grid** 준수 | 전체 레이아웃이 정의된 그리드 시스템(예: 12단 그리드 또는 특정 비율) 내에서 정렬되었는가? | 좌표 및 간격 검증 | | |
| 2.4 | **Element Density** 관리 | 정보 과부하 없이 시각적 여백(Whitespace)이 충분히 확보되어 가독성을 높였는가? | 공백 비율 측정 | | |

## 📦 섹션 3: 자산 라이브러리 통합 (Asset Library Integration)
| No. | 검증 항목 | 기준 (Visual Asset Library 기반) | 자동화 체크 방식 | 통과 여부 (Y/N) | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 3.1 | **Pattern Usage** | 라이브러리 내에서 승인된 전환점 강조 패턴(Transition Patterns) 중 최소 1개 이상이 적용되었는가? | 패턴 ID 매칭 검사 | | |
| 3.2 | **Style Consistency** | 사용된 모든 그래픽 요소(아이콘, 도형 등)가 라이브러리 내의 스타일 가이드라인을 따르는가? | Style Tagging 시스템 확인 | | |

## ✅ 최종 승인 기준 (Final Approval Criteria)
모든 썸네일/자산은 위 세 섹션의 **모든 항목**에서 'Y'를 획득해야만 자동 생성 및 배포가 허용된다.
