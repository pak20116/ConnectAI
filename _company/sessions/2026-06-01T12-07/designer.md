## ✨ 자동화 시스템 일관성 최종 검증 체크리스트 (Visual Consistency Audit)

본 체크리스트는 모든 자동 생성된 시각 자산(썸네일, 포스트 등)이 사전에 정의된 브랜드 가이드라인을 엄격하게 준수하는지 확인하기 위해 설계되었습니다.

### I. 컬러 및 톤 일관성 검증 (Color & Tone Consistency)

| # | 검증 항목 | 기준 사양 | 검증 결과 (PASS/FAIL) | 비고 (발생 시 수정 지점) |
| :---: | :--- | :--- | :--- | :--- |
| 1.1 | **Primary Color 적용** | `#2C3E50` (핵심 구조 및 타이틀 영역) | | |
| 1.2 | **Accent Color 적용** | 강조색 (Focus/Escape 변화 지점, CTA 버튼 등) | | |
| 1.3 | **보조 색상 사용** | 배경 및 보조 정보(Subtext)에 사용된 중립 색상 팔레트 준수 여부 | | |
| 1.4 | **톤 앤 매너** | 전체 디자인이 '전문적이고 기술적인' 느낌을 유지하는지 (색상 대비, 명암 처리 포함) | | |

### II. 타이포그래피 및 계층 구조 검증 (Typography & Hierarchy)

| # | 검증 항목 | 기준 사양 | 검증 결과 (PASS/FAIL) | 비고 (발생 시 수정 지점) |
| :---: | :--- | :--- | :--- | :--- |
| 2.1 | **폰트 사용** | 확정된 브랜드 타이포그래피 시스템 적용 여부 | | |
| 2.2 | **헤드라인 계층** | H1 (핵심 메시지), H2 (구조 설명), Body Text의 크기 및 굵기 비율 준수 여부 | | |
| 2.3 | **Focus/Escape 강조** | 'Focus' 상태와 'Escape' 상태를 시각적으로 구분하는 폰트 크기, 색상 대비 규칙 적용 여부 | | |

### III. 레이아웃 및 구조 일관성 검증 (Layout & Structure Consistency)

| # | 검증 항목 | 기준 사양 | 검증 결과 (PASS/FAIL) | 비고 (발생 시 수정 지점) |
| :---: | :--- | :--- | :--- | :--- |
| 3.1 | **핵심 레이아웃** | 'Focus $ \rightarrow$ Escape' 구조(Split Screen 또는 대비 강조)가 모든 디자인에 적용되었는지 | | |
| 3.2 | **정보 배치 규칙** | 로고, CTA 버튼, 핵심 메시지가 지정된 영역 내에 정확히 위치하는지 (좌표/여백 기준) | | |
| 3.3 | **여백(Whitespace)** | 하이브리드 디자인 원칙(#2C3E50 기반)에 따른 적절한 여백 비율 유지 여부 | | |

### IV. 비주얼 자산 및 라이브러리 검증 (Asset & Library Consistency)

| # | 검증 항목 | 기준 사양 | 검증 결과 (PASS/FAIL) | 비고 (발생 시 수정 지점) |
| :---: | :--- | :--- | :--- | :--- |
| 4.1 | **패턴 라이브러리 사용** | '전환점 강조 패턴' 중 최소 2종 이상이 콘텐츠에 전략적으로 적용되었는지 | | |
| 4.2 | **구조도 애니메이션** | 데이터 구조나 시스템 흐름을 시각화하는 모듈(VSM)이 일관된 스타일로 구현되었는지 | | |
| 4.3 | **자산 품질** | 사용된 모든 그래픽 요소의 해상도 및 파일 포맷이 최적화되어 있는지 | | |
