## 🚀 Sales Page Hero Section 디자인 브리프 (초안)

**목표:** 방문자가 페이지를 로드하는 순간, 시스템의 안정성과 시각적 일관성이 즉각적으로 신뢰감을 주도록 설계합니다. 기술적 우위를 감성적 가치로 전환하여 프리미엄 포지셔닝을 확보합니다.

### 1. 디자인 컨셉: Optimized Trust (최적화된 신뢰)

**핵심 메시지:** "불안정한 결과물은 이제 그만. 시스템 안정성이 보장하는 완벽한 콘텐츠 자동화."

**톤앤매너:** 전문적, 기술 중심적, 미니멀리즘, 고성능(High-Performance).

### 2. 컬러 팔레트 (Color Palette)

기존의 전문적인 시각 시스템을 활용하되, 안정성과 성공을 상징하는 색상을 추가하여 KPI를 강조합니다.

| 요소 | 색상 코드 | 용도 및 의미 |
| :--- | :--- | :--- |
| **Primary (배경/텍스트)** | `#2C3E50` (Dark Slate Blue) | 전문성, 기술적 깊이, 안정성 (기존 시스템 유지) |
| **Secondary (강조/CTA)** | `#1ABC9C` (Turquoise) | 최적화, 성공, 연결, 혁신 (긍정적인 KPI 강조) |
| **Accent (경고/안정)** | `#F39C12` (Amber/Orange) | 주의 사항, Latency 경고 또는 잠재적 개선점 표시 (KPI 시각화용) |
| **Background** | `#FFFFFF` (White) 또는 매우 연한 회색 (`#F8F9FA`) | 깨끗함, 명료성, 콘텐츠 집중 |

### 3. 타이포그래피 (Typography)

기술적 정확성과 가독성을 최우선으로 합니다.

*   **헤드라인 (H1):** Bold하고 넓은 자간(Letter Spacing)을 사용하여 기술적 자신감을 표현합니다. (예: `Montserrat` 또는 `Inter`, 굵게)
*   **서브 헤드라인:** 명확하게 구조화하여 KPI를 강조하는 데 사용됩니다.
*   **본문:** 높은 가독성을 위해 충분한 행간(Line Height)을 확보합니다.

### 4. 레이아웃 및 시각 요소 (Layout & Visual Elements)

Hero 섹션은 크게 **[핵심 헤드라인]**, **[기술적 신뢰 지표]**, **[주요 CTA]** 세 부분으로 구성됩니다.

#### A. 상단 (Above the Fold - 시선 집중 영역)

1.  **메인 헤드라인 (H1):**
    *   **내용:** "Chaos to Control: Latency와 일관성을 보장하는 AI 썸네일 자동화 시스템" (KPI 직접 언급)
    *   **스타일:** `#2C3E50` 배경 위에 `#FFFFFF`로 대비시켜 명확하게 강조.

2.  **핵심 시각 요소 (Visual Anchor):**
    *   시스템 안정성(Consistency Score)을 상징하는 미니멀한 **Progress Bar 또는 Gauge**를 배치합니다. 이 바는 현재 시스템의 `VisualConsistencyScore`가 목표치에 얼마나 근접했는지 시각적으로 보여줍니다. (색상: `#1ABC9C`)

#### B. 중앙 영역 (신뢰 구축 - KPI 강조)

이 부분은 기술적 지표를 단순한 숫자가 아닌 **보증**으로 전환합니다.

*   **KPI 카드 배치:** `Latency_ms`와 `VisualConsistencyScore`를 분리하여 두 개의 명확한 '안정성 카드'로 구성합니다.
    *   **카드 1: Latency Guarantee (지연 시간 보장)**
        *   **표시:** 현재 평균 Latency 값과 임계값(`LATENCY_THRESHOLD_MS = 100ms`)을 비교하여 표시합니다.
        *   **디자인:** Latency 값이 목표치(100ms) 이하라면 **녹색 체크 표시(OK)**를, 초과하면 **주황색 경고 표시(WARNING)**를 사용하여 즉각적인 상태를 전달합니다.
    *   **카드 2: Visual Consistency Score (시각적 일관성)**
        *   **표시:** 현재 `VisualConsistencyScore` 값을 시각화된 게이지로 보여줍니다. (예: 98% 달성)
        *   **디자인:** 이 점수가 높을수록 시스템의 가치를 증명한다는 느낌을 주도록 디자인합니다.

#### C. 하단 (Call to Action - 행동 유도)

1.  **CTA 버튼:**
    *   **텍스트 예시:** "시스템 안정성 확인 및 무료 체험 시작" 또는 "최적화된 자동화 시스템 경험하기"
    *   **스타일:** 가장 강렬한 색상인 `#1ABC9C`를 사용하여 클릭을 유도합니다.

### 5. 개발자에게 전달할 구체적인 요구사항 (Action Items for Developer)

개발자님께서는 이 브리프를 기반으로 실제 FIGMA에 적용하실 때 다음 사항을 반드시 고려해 주십시오.

1.  **데이터 연동 방식:** Latency 및 Consistency Score가 동적으로 페이지 로드 시 실시간(혹은 캐시된) 데이터로 표시되도록 API 또는 데이터 바인딩 구조를 준비해야 합니다.
2.  **경고 시스템:** `Latency_ms`가 임계값을 초과할 경우, Hero 섹션 전체의 배경 색상을 잠시 `#F39C12` (Amber) 톤으로 미묘하게 변경하여 시각적 긴급성을 부여하는 로직을 고려해 주십시오.
3.  **템플릿화:** 이 디자인 구조는 향후 모든 시스템 안정성 관련 페이지(예: 대시보드, 가격 페이지)에 일관되게 적용될 수 있도록 컴포넌트 기반으로 설계되어야 합니다.
