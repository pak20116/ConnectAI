# 🖼️ The System Blueprint: 최종 디자인 브리프 (The System Blueprint Final Design Brief)

**목표:** 'Focus'와 'Escape'의 극적인 대비를 통해 시청자의 시선을 즉각적으로 사로잡고, 콘텐츠의 핵심 메시지(자가학습 시스템 구축)에 대한 전문성과 구조적 전환점을 강조하여 최고 CTR을 유도한다.

**브랜드 가이드라인 적용 (Cortexa Identity):**
*   **주조색 (Primary Color):** `#2C3E50` (Deep Slate Blue/Navy) - 전문성, 신뢰감, 기술적 깊이를 표현.
*   **보조색 (Accent Color):** `#ECF0F1` (Light Gray/Off-White) - 배경 및 대비를 위한 깨끗함과 공간감을 제공.
*   **강조색 (Contrast Color):** `#E74C3C` (Vibrant Red/Orange) - 'Escape' 또는 'Focus'의 극적인 전환점, 긴급성, 행동 유도(CTA) 강조에 사용.

## 1. 시각 컨셉 정의: Focus & Escape 대비 구조

이 디자인은 화면을 **명확하게 두 영역**으로 분할하여, 시청자가 콘텐츠를 소비하는 동안 경험하는 심리적 상태의 변화(Focus $\rightarrow$ Escape)를 시각적으로 표현해야 합니다.

### 1.1. 레이아웃 (Layout Structure): 50:50 분할 전략
*   **상단 영역 (Top 50% - Focus Zone):** 시스템, 학습, 집중을 상징하며 **`#2C3E50`** 계열의 어둡고 구조적인 디자인을 적용합니다. (Focus)
*   **하단 영역 (Bottom 50% - Escape Zone):** 자유로움, 해방감, 결과물을 상징하며 **`#ECF0F1`** 배경과 강조색을 사용하여 시각적 대비를 극대화합니다. (Escape)

### 1.2. 타이포그래피 규칙 (Typography Rules)
*   **제목/핵심 메시지 (Focus Zone):** 산세리프 계열의 두꺼운 폰트(예: Montserrat Bold, Bebas Neue)를 사용하여 구조적이고 단호한 느낌을 부여합니다. 색상은 `#ECF0F1` 또는 `#2C3E50`.
*   **보조 설명 (Escape Zone):** 가독성이 높은 산세리프 계열의 중간 굵기(예: Roboto, Inter)를 사용하여 내용 전달에 집중하게 합니다.
*   **핵심 대비 요소:** 'Focus'와 'Escape'라는 키워드는 서로 다른 폰트 스타일이나 색상을 사용하여 시각적 위계를 명확히 분리합니다.

## 2. 디자인 요소 상세 스펙 (Element Specifications)

| 요소 | 역할 | 적용 스타일/색상 | 위치 및 특징 |
| :--- | :--- | :--- | :--- |
| **배경** | 전체 배경 | `#ECF0F1` (밝은 회색) | 이미지 영역 전체를 채움. |
| **Focus 영역** | 상단 구조 | `#2C3E50` (짙은 네이비) | 상단 50% 영역에 배치. 시스템의 '구조'를 시각화. |
| **Escape/Contrast** | 핵심 메시지 강조 | `#E74C3C` (강렬한 레드) | 전환점(중앙 경계선 또는 하단 섹션 시작점)에 사용. |
| **텍스트 배치** | 'Focus' 텍스트 | Bold, 대문자 스타일 | 상단 영역의 핵심 주제를 명확히 제시. |
| **텍스트 배치** | 'Escape' 텍스트 | Regular/Semi-Bold | 하단 영역에서 결과나 자유로움을 표현. |

## 3. 최종 실행 가이드 (Execution Guide for Automation)

1.  **구조 설정:** 이미지 프레임을 수평으로 정확히 50% 지점에서 분할합니다.
2.  **색상 매핑:** 상단은 `#2C3E50` 배경, 하단은 `#ECF0F1` 배경으로 설정합니다.
3.  **대비 강조:** 중앙 경계선 또는 'Focus' 영역의 핵심 단어에 **`#E74C3C`** 색상을 사용하여 시각적 충돌과 주목도를 극대화합니다.
4.  **폰트 적용:** Focus 텍스트는 크고 굵게, Escape 텍스트는 명확하게 분리하여 배치합니다.
