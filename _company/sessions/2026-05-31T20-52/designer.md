CEO 지시에 따라, 확정된 브랜드 가이드라인(#2C3E50)과 고품질 썸네일 자산을 기반으로 영상 편집 흐름을 원활하게 할 수 있도록 인트로/아웃트로 디자인 요소를 최종 점검하고 준비하겠습니다. 이는 전체 비주얼 시스템의 일관성을 확보하는 데 중점을 둡니다.

**핵심 목표:** 브랜드 아이덴티티를 반영한, 통일성 있고 전문적인 영상 시작 및 끝 프레임을 정의합니다.

### 🎬 인트로/아웃트로 디자인 최종 점검 및 준비안

기존에 확정된 브랜드 가이드라인(**Primary Color: #2C3E50**, 전문적이고 기술적인 톤)을 적용하여, 시청자의 몰입을 방해하지 않으면서도 채널의 전문성을 강조하는 인트로/아웃트로 디자인 요소를 다음과 같이 정의하고 준비합니다.

#### 1. 비주얼 컨셉: 'Focus & Escape'의 연결고리

인트로와 아웃트로는 콘텐츠 본론(Body)과 명확히 구분되면서도, 브랜드의 핵심 감정선인 **'집중(Focus)'에서 '탈출/몰입(Escape)'**으로 자연스럽게 전환되는 시각적 다리 역할을 해야 합니다.

#### 2. 인트로 (Intro) 디자인 사양

| 요소 | 상세 지침 | 적용 규칙 |
| :--- | :--- | :--- |
| **배경** | 깊고 어두운 색상(Primary Color #2C3E50 또는 그보다 짙은 차콜톤). 미세한 입자 또는 빛 번짐 효과를 사용하여 기술적이고 몰입감 있는 분위기 조성. | `#2C3E50` (Dark Mode Base) |
| **로고 배치** | 화면 중앙 상단에 작게 배치하거나, 전체 화면을 덮는 은은한 그라데이션 형태로 처리하여 시각적 무게중심을 잡아줍니다. | 로고 색상: 흰색 (#FFFFFF) 또는 밝은 회색 (#BDC3C7) |
| **타이포그래피** | 채널 이름(Cortexa)을 산세리프 계열의 모던하고 얇은 폰트(예: Montserrat Light, Roboto Thin)로 중앙에 배치. | 폰트: Montserrat/Roboto 계열 (Thin 또는 Light) |
| **길이** | 약 3~5초 이내로 짧고 간결하게 구성하여 시청자가 바로 본론으로 진입하도록 유도합니다. | - |

#### 3. 아웃트로 (Outro) 디자인 사양

| 요소 | 상세 지침 | 적용 규칙 |
| :--- | :--- | :--- |
| **배경** | 인트로와 동일한 다크톤을 유지하되, 마무리되는 순간 시각적 에너지를 서서히 줄여나가는 느낌을 연출합니다. | `#2C3E50` 기반의 부드러운 페이드 아웃(Fade Out) 적용. |
| **CTA 영역** | 구독/좋아요 요청 메시지를 명확하게 배치합니다. 시각적 요소는 최소화하고 텍스트에 집중하여 행동 유도(CTA)를 극대화합니다. | CTA 문구: "다음 몰입을 위해 구독하세요." (간결한 서체 사용) |
| **음악 연출** | 영상의 마지막 몇 초 동안 배경 음악이 점진적으로 페이드 아웃되도록 사운드 믹싱에 반영하여 마무리감을 극대화합니다. | - |

#### 4. 썸네일과의 연결성 확보 (Consistency Check)

*   **색상 일관성:** 인트로/아웃트로의 메인 컬러(#2C3E50)는 모든 썸네일과 영상 내 그래픽 요소에 사용된 보조 색상 팔레트(Accent Colors)의 근간이 됩니다.
*   **폰트 계층:** 인트로에서 사용된 모던하고 얇은 서체 스타일을 아웃트로 CTA에도 일관되게 적용하여, 채널 전체의 타이포그래피 위계를 확립합니다.
