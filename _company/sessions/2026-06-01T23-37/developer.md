<create_file path="sessions/error_log_standard.md"># 에러 로그 표준 포맷 (Design Guideline)

## 📝 목표
시스템 안정성 확보 및 KPI 추적을 위해 모든 실패 이벤트에 대해 일관된 형식으로 로그를 기록한다. 이 포맷은 시스템 흐름(System Flow)과 데이터 매핑 로직의 실패 지점을 명확히 식별하는 데 사용된다.

## ⚙️ 필수 필드
모든 에러 로그는 다음 필드를 반드시 포함해야 한다.

1. **`timestamp` (필수):** 오류 발생 시점 (ISO 8601 형식).
2. **`pipeline_id` (필수):** 해당 오류가 발생한 시스템 파이프라인 또는 모듈의 고유 ID. (예: 'thumbnail_generation', 'data_etl')
3. **`error_code` (필수):** 표준화된 에러 코드. 사전에 정의된 코드를 사용한다. (예: `E_API_401`, `E_DATA_MISSING`, `E_FLOW_VIOLATION`)
4. **`severity` (필수):** 오류의 심각도. (`CRITICAL`, `ERROR`, `WARNING`, `INFO`)
5. **`module` (필수):** 오류가 발생한 시스템 모듈 또는 함수 단위.
6. **`message` (필수):** 에러에 대한 상세하고 명확한 설명. (개발자가 이해할 수 있는 자연어)
7. **`context` (선택):** 오류 발생 당시의 주요 컨텍스트 정보. (예: 입력 데이터 샘플, 실패한 단계 번호 등)
8. **`traceback` (선택):** 스택 트레이스 전체 내용.

## 📊 예시 포맷 (JSON 형식 권장)
실제 로그는 JSON 형식으로 기록되어야 하며, 아래와 같은 구조를 따른다.

```json
{
  "timestamp": "2026-06-01T23:22:00Z",
  "pipeline_id": "thumbnail_generation",
  "error_code": "E_API_401",
  "severity": "ERROR",
  "module": "API_Service",
  "message": "썸네일 생성 API 호출 시 인증 오류가 발생했습니다. API 키가 만료되었거나 권한이 부족합니다.",
  "context": {
    "endpoint": "/generate/thumbnail",
    "attempt": 1,
    "user_id": "user_abc123"
  },
  "traceback": "Traceback (most recent call last):\n  File \"...\", line X, in function\n    raise PermissionError(\"API Key expired\")"
}
```

## 📌 적용 규칙
- 모든 실패 지점은 위 필드를 사용하여 로그를 기록해야 한다.
- `error_code`는 사전에 정의된 코드 목록을 엄격히 준수한다. (추후 정의 예정)
- `context` 필드는 디버깅에 필수적이므로, 오류 발생 시 최대한 상세한 정보를 포함하도록 설계한다.
