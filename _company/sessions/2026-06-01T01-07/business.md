### 📊 Tier 2 'Consistency Pack' 최종 명세 및 수익화 전략

#### 1. 기능 명세 (Functional Specification)
**제품명:** Consistency Pack (Tier 2: Focus & Escape Engine)
**핵심 가치:** 시청 지속률(Audience Retention) 극대화 보장.
**목표:** 사용자가 콘텐츠를 이탈하기 전에 개입하여 몰입도를 유지하고, 궁극적으로 수익 창출 기회 증대.

| 기능 모듈 | 상세 기능 설명 | 기술적 구현 목표 | 핵심 지표 (KPI) |
| :--- | :--- | :--- | :--- |
| **Real-time Drop-off Monitor** | 영상 재생 중 실시간으로 시청 지속률을 측정하고, 설정된 임계값(예: 5분 이탈 예측) 도달 시 알림을 발생시킵니다. | VSM Engine의 데이터 스트림과 연동하여 실시간으로 데이터를 수집 및 계산하는 API 엔드포인트 구축. | **Real-time Drop-off Rate** (실시간 이탈률), **Prediction Latency** (예측 지연 시간) |
| **VSM Feedback Loop** | 특정 시각적 전환점(VSM)이 발생했을 때, 해당 구간의 시청 지속률 변화를 분석하여 다음 콘텐츠 제작에 대한 피드백을 제공합니다. | VSM Engine 결과와 Real-time 데이터를 결합하여, 어떤 편집 포인트가 이탈률에 가장 큰 영향을 미쳤는지 분석하는 보고서 자동 생성 로직. | **VSM Impact Score** (시각적 전환점의 영향력 점수) |
| **Adaptive Suggestion** | 모니터링 결과에 따라 사용자에게 맞춤형 다음 콘텐츠 추천 또는 영상 내 편집 가이드라인(Focus & Escape 적용 방안)을 제공합니다. | LLM 기반으로 데이터 분석 결과를 해석하여, 'Focus & Escape' 전략에 맞는 구체적인 텍스트 및 시각적 수정 제안 생성. | **Suggestion Acceptance Rate** (제안 수용률), **Engagement Lift** (참여도 향상 지수) |

#### 2. 데이터 요구사항 (Data Requirements)
실시간 대시보드와 예측 모델의 정확성을 보장하기 위해 다음과 같은 데이터 스트림이 필수적으로 필요합니다.

1.  **영상 메타데이터:** 영상 ID, 업로드 시간, 길이, 시청자 인구통계(선택 사항).
2.  **시청 행동 로그 (Core Data):** 각 영상별 **Timestamp** 단위의 시청 지속률 데이터 (0초부터 끝까지의 구간별 이탈률 기록).
3.  **VSM 매핑 데이터:** 영상 내 특정 시간대(예: 5분 지점)에서 어떤 VSM이 적용되었는지에 대한 메타데이터.
4.  **사용자 설정 데이터:** 사용자가 설정한 'Focus & Escape' 임계값 및 선호하는 콘텐츠 스타일.
