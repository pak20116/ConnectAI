# 최종 Sales Page 레이아웃 및 게이지 디자인 사양
## 1. 브랜드 시스템 적용 (Brand System Application)
| 요소 | 설정값 | 설명 |
| :--- | :--- | :--- |
| **Primary Color** | `#2C3E50` (짙은 네이비/차콜) | 신뢰감, 전문성, 기술적 깊이 강조. |
| **Accent Color** | `#1ABC9C` (청록색) | 성취, 안정감, 긍정적인 변화(제거된 불확실성)를 시각화. |
| **Background** | `#F4F7F8` (매우 밝은 회색) | 콘텐츠에 집중하도록 명료하고 깨끗한 배경 제공. |
| **Typography (Headings)** | Inter Bold / Montserrat SemiBold | 현대적이고 전문적인 느낌을 유지. |

## 2. 최종 Sales Page 레이아웃 구조 (Final Layout Structure)
Sales Page는 상단에서 하단으로 흐르는 명확한 시각적 흐름(Visual Flow)을 가져야 하며, KPI 게이지 컴포넌트가 중앙에 위치하여 **핵심 가치 증명**의 중심이 되도록 설계합니다.

| 섹션 | 구성 요소 | 디자인 목표 및 내용 |
| :--- | :--- | :--- |
| **A. Hero Section (상단)** | H1 제목, 서브헤드, 핵심 CTA 버튼 | 가장 강력한 UVP("불확실성 제거")를 제시하고 즉각적인 행동을 유도. 배경은 미니멀하게 처리하여 시선 집중. |
| **B. Problem/Solution (문제 제기)** | 문제점 나열 및 해결책 제시 | 사용자가 겪는 '추측과 불확실성'의 문제를 명확히 정의하고, 시스템이 이를 어떻게 제거하는지 간략히 설명. |
| **C. Proof Section (핵심 증명 - **중앙 집중**) | **KPI 게이지 컴포넌트** | Latency와 Consistency Score를 시각적으로 표시하여 '자동화된 확신'을 직접 증명. 이 섹션이 페이지의 심장부여야 함. |
| **D. Feature Deep Dive (기능 상세)** | 상세 기능 목록 및 원리 설명 | KPI가 어떻게 작동하는지(기술적 근거)를 간결하게 설명하여 신뢰도를 확보. |
| **E. Pricing & CTA (가격 및 행동 유도)** | 가격 모델($299/$399) 제시, 최종 CTA | 프리미엄 가치($299-$399)가 단순한 비용이 아닌 '불확실성 제거에 대한 투자'임을 강조하며 최종 구매를 유도.

## 3. 핵심 컴포넌트 디자인: KPI 게이지 컴포넌트 상세 사양
**컴포넌트 명:** Uncertainty Gauge (불확실성 측정 게이지)

### 3.1. 레이아웃 및 구조
*   **위치:** 섹션 C (Proof Section)의 중앙에 배치.
*   **구조:** 두 개의 독립된 게이지를 나란히 배치하고, 그 아래에 통합된 '불확실성 제거' 메시지를 삽입합니다.

### 3.2. Latency Gauge 디자인 (속도/안정성 시각화)
*   **제목:** **Predictable Performance** (예측 가능한 성능)
*   **게이지 범위:** 0ms ~ 최대 허용치 (예: 500ms).
*   **색상 로직:**
    *   **Green Zone (안정):** Latency가 최적 범위(예: <300ms)에 있을 때, **Accent Color (`#1ABC9C`)**로 채워지며 "Uncertainty Erased" 상태를 시각적으로 표현.
    *   **Yellow Zone (주의):** 경고 범위(예: 300ms ~ 500ms)에 있을 때, 노란색으로 표시하며 '잠재적 불확실성'을 암시.
    *   **Red Zone (위험):** 최대 허용치를 초과할 때, 빨간색으로 표시하여 위험 신호를 명확히 경고.

### 3.3. Visual Consistency Score Gauge 디자인 (품질/일관성 시각화)
*   **제목:** **Automated Confidence** (자동화된 확신)
*   **게이지 범위:** 0% ~ 100%.
*   **색상 로직:**
    *   **Green Zone (최고 품질):** Consistency Score가 높을수록(예: 90% 이상), **Accent Color (`#1ABC9C`)**로 채워지며 '완벽한 일관성'을 표현.
    *   **Gray Zone (보통):** 중간 수준일 때 회색 계열로 표시.
    *   **Red Zone (불일치):** 일관성이 낮을 때(예: 70% 이하), 경고 색상으로 표시하여 결과의 신뢰도가 떨어진다는 것을 시각적으로 알림.

### 3.4. 최종 메시지 통합
게이지 아래에 다음 문구를 배치하여 디자인의 의도를 명확히 합니다.
> **"Latency와 일관성(Consistency)이 자동으로 보장됩니다. 당신은 이제 추측 대신 확신을 선택합니다."**
