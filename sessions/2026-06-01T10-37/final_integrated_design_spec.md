# Final Integrated Design Specification: Focus $\rightarrow$ Escape System
## 🎯 Core Principle
Focus (Pain) $\rightarrow$ Escape (Freedom) Transition, driven by the 'Focus & Escape' emotional flow.

## 🎨 Visual System Rules
1.  **Primary Color:** `#2C3E50` (Deep Slate Blue) - Represents Focus/Pain.
2.  **Accent Color:** A contrasting vibrant color (e.g., a bright, energetic yellow or cyan) for the 'Escape' element.
3.  **Layout Structure (Split Screen):** Strict Split Screen to visually represent the transition:
    *   **Left Side (Focus/Pain):** Dominated by dark, heavy elements using `#2C3E50`. Visuals should be dense, complex, or frustrating (representing the 'Focus' state).
    *   **Right Side (Escape/Freedom):** Lighter, more open, and visually expansive. Use the Accent Color to draw attention to the solution or relief (representing the 'Escape' state).
4.  **Typography:** Bold, technical, and highly legible sans-serif fonts. Focus on clear hierarchy.
5.  **Transition Point:** A sharp, diagonal line or visual gradient shift between the two sides to emphasize the transition from pain to freedom.

## 🎬 Storyboard Template (Template for Automation)
| Stage | Emotional State | Visual Goal | Color Palette Emphasis | Text Placement Strategy |
| :---: | :---: | :---: | :---: | :---: |
| **Focus** | Pain/Struggle | Dense, Complex System Visualization | `#2C3E50` (Dominant) | Large, urgent text emphasizing the problem or complexity. |

| **Escape** | Freedom/Relief | Open Space / Solution Visualization | Accent Color (Dominant) | Clear, aspirational text emphasizing the solution or outcome. |

## ⚙️ Automated Output Rule
The system must dynamically generate a visual composition adhering strictly to the Split Screen structure and the Focus $\rightarrow$ Escape color transition for every thumbnail request. The final output image must be highly optimized for CTR maximization by maximizing the emotional contrast between the two halves.
